claude of tanks

ar·mor — the working model · rendered live in your browser 90 vehicles · 8 battlefields · tiers I–X · three.js

A complete armored-warfare technology demo: procedurally built tanks measured against reference geometry, eight hand-tuned battlefields, a five-bus sound stage with a radio crew, and a scene studio for staging shots like the ones on this page. No installs, no accounts — it runs where the browser is.

03The fleet

measured, not eyeballed

Every hull in the library is being rebuilt from scratch against reference geometry and published dimensions — a tank ships only when every measured component scores ≥ 90 and an independent critic scores every view ≥ 9/10 for shaded parity. The scoreboard so far:
