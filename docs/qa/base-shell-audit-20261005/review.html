How to read the results

Counts show matched base parts whose sampled mirrored surfaces differ by more than 5 mm. They are review candidates, not failed release tests. Curved castings, covered supports and deliberate asymmetry need visual classification. Unmatched parts are not presumed broken. Warped-slab flags identify non-planar faces, including valid designed facets. Decorations, separate guns and overlays are excluded as described in the report.
