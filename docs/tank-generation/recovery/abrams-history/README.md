# Historical Abrams working notes

These thirty files are verbatim copies of the integrated, unpublished Abrams
research notes recovered on 2026-09-09. Their dates, “nothing committed” text,
scores, command outputs, absolute worktree paths, and pending states describe
earlier checkpoints. They are not current qualification or publishing policy.

Read [the current recovery handoff](../abrams-seven-preservation-20260909.md)
first. The [source manifest](../abrams-seven-source-manifest-20260909.json)
records each original/integrated document hash and its archival location.
Historical relative links outside this directory refer to the original repo
layout; the original and integrated roots are recorded in that manifest.

The source reconstruction history starts with [the working contract](abrams-source-x.md),
[variant configuration](abrams-source-x-variants.md), and
[selected surface corrections](abrams-source-x-user-surfaces-r5.md).
