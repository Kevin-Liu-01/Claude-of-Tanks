# T-72B obr. 1987 (`t72b_1987`)

**Exact variant modeled:** T-72B model 1987 — "Super Dolly Parton" thickened
cast turret cheeks fully rafted with Kontakt-1 brick ERA (227-tile fit:
glacis raft + turret front arc + first skirt panels), 2A46M gun, 1K13-49
sight. Distinct from T-72A (no ERA, thinner cheeks), from T-72B3 (K-1 → soft
bags + Sosna-U), and from T-90 (no Shtora eyes).

## Identity cues

- Turret: fat-cheeked cast dome (~3.2 m) — K-1 bricks angled in fan arrays
  covering the front 60° each side plus roof edge rows; dome widest near
  mid-rear; smoke tubes bank LEFT cheek only (902B).
- Mantlet/gun: 2A46M with sleeve + mid evacuator; 1K13 sight hood left roof.
- Hull front: full-width K-1 glacis raft (~4 rows, tilted back).
- Rear: two fuel drums + unditching log on hull rear plate.
- Running gear: 6 wheels, rubber skirts, front mudflaps.
