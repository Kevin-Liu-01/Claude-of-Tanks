# M1A1 Abrams — reference packet

Variant: M1A1 (pre-SEP). Real M1A1 has NO CITV and NO CROWS — commander's
.50 cal on a manual station; same M256 L/44 as later marks.

## Real-vehicle dimensions
- Hull ~7.92 m, overall 9.77 m, width 3.66 m, height 2.44 m, M256 L/44
  (~5.28 m tube). 7 road wheels, rear sprocket.
  Sources: GlobalSecurity (https://www.globalsecurity.org/military/systems/ground/m1-specs.htm),
  Wikipedia M1 Abrams (https://en.wikipedia.org/wiki/M1_Abrams),
  Tank Encyclopedia (https://tanks-encyclopedia.com/coldwar/us/m1_abrams.php).
