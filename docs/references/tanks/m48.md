Exact vehicle: **M48A5 Patton** — the 1975-79 refit of the M48A3 fleet to the
M60's **105 mm M68** gun + AVDS-1790-2D RISE diesel. Boat-bow cast hull
(rounded prow, raked one-plane glacis), hemispherical cast turret, low-profile
(Urdan-class) commander cupola on the print, 6 road wheels + 5 return rollers +
low track-tension idler, rear drive sprocket, full-length fenders with

hull grammar (M48A5 = M48 hull + the M60 105 mm) + the patton-lane cast-turret
grammar (`t26Cast` carries the §5.47 ring-cupola class this print reads);
**the print governs proportions**.
