# M60A3 — reference packet

Exact vehicle: **105mm Gun Tank M60A3 (TTS)** — same hull/turret geometry as
the M60A1 RISE, with the fire-control upgrades: **thermal sleeve on the M68**,
laser rangefinder, tank thermal sight, usually **no searchlight**; M19 cupola
retained.

## Real dimensions (2+ sources)
- Dimensions identical to M60A1: hull **6.946 m**, gun forward **9.436 m**
  (spec row; Wikipedia lists 9.309 m for the A1 — same tube), width
  **3.631 m**, height **3.27 m** —
  [Wikipedia: M60 tank](https://en.wikipedia.org/wiki/M60_tank)
- [FAS: M60 series](https://man.fas.org/dod-101/sys/land/m60.htm) — M60A3
  laser RF + thermal sight; geometry unchanged from A1.
- Suspension: 6 road wheels, 3 return rollers, rear sprocket, front idler.
- Photos: [Wikimedia Commons: M60A3](https://commons.wikimedia.org/wiki/Category:M60A3_Patton).
