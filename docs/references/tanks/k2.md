1. **FITTINGS-IMPORT-ONLY (module-cycle lesson, hit live this round)**:
   inside the tankFactory extension-module cycle the ONLY safe fittings

   first cut invented one and threw at build; and `KIT.fittings` is only

   extension module) as the ENTRY throws kit.js's `Cannot access 'KIT'
   before initialization` TDZ even when the code is correct.
2. **SWEPT-PLANAR CORE (§B1 mechanism)**: behind plan-swept raked
   cheeks, an axis-aligned core frustum ALWAYS fails one of two ways —
   its upper front corner pokes through the rake (slope-motivates-the-
   mass violation; v1 measured here) or, pulled back, it opens a
   top-down valley behind the cheeks. Fix: split the core into L/R
   half-slabs whose VERTICAL front faces lie ON the cheek top-rear edge
   line (z = c − m·|x|); the roof then continues flat off the cheek tops
   with zero poke and zero valley. Corner-swap the L half (§C winding).
3. **CHEEK-APEX GLACIS SEAT**: a wedge turret whose apex overhangs the
   glacis crest floats above the raked plane (0.056 here) — sink the
   cheek/filler bottom rings below turret-local 0 (−0.08) so the slabs
   seat INTO the hull solid; the sink is interior (mask-free, yaw-safe)
   and closes the §B2 gap without a chin wedge.
