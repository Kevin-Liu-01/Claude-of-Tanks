# M60A1 — reference packet

Exact vehicle: **105mm Gun Tank M60A1** — the long-nose ("needle-nose")
elongated cast turret with the big rear bustle, **M19 commander's cupola**
(own .50cal M85), **M68 105 mm** gun (British L7 tube; bore evacuator toward
mid-tube, no muzzle brake), AN/VSS-1 searchlight over the mantlet on many
vehicles; flat-topped boat hull with long shallow glacis.

## Real dimensions (2+ sources)
- Hull length **6.946 m**; length gun forward **9.309 m** (M68 overhang
  ≈ 2.4 m); width **3.631 m**; height **3.27 m** —
  [Wikipedia: M60 tank](https://en.wikipedia.org/wiki/M60_tank)
- [FAS: M60 series](https://man.fas.org/dod-101/sys/land/m60.htm) — M60A1
  L 31 ft, W 11 ft 11 in, H 10 ft 8 in; M68 105 mm; M19 cupola with 7 vision
  blocks.
- Suspension: **6 road wheel pairs, 3 return rollers**, rear drive sprocket,
  front compensating idler (Wikipedia, same article).
- Photos: [Maloney: Patton Museum M60A1](https://www.williammaloney.com/Aviation/PattonMuseum/M60A1MainBattleTank/index.htm),
  [Wikimedia Commons: M60A1](https://commons.wikimedia.org/wiki/Category:M60A1_Patton).
