# Batch 30 plan — Endless Horde and Frontline as designed (owner 2026-09-15 evening)

Owner: "for frontline and endless horde there needs to be custom team arrangement settings
(for endless horde the horde is not endless, there's only 3 tanks every time which is low and
they're the same tanks each round). frontline was misinterpreted: it has to be a completely
new campaign experience set on the custom maps where there are waves of actually same-nation
enemies; the custom maps are actual battlefields with trenches and more."

## Findings (research map, 2026-09-15)
- Horde wave = `HORDE_INITIAL_ACTIVE (3) + floor((wave-1)/2)` entities, always the FIRST k of a
  frozen `hordeEnemies` array (src/sim/matchModes.ts:496-516) — same tanks, same pads; the
  pool is 11 bots in solo (13 - allies 2) and only `teamSize` (1-7) bots in rooms.
- `MatchRuleset.enemies` (src/sim/matchRuleset.ts:53) is declared, pinned, never read.
- Frontline solo prefers the operation's nation (`preferNations`, cap 10); a free sortie or
  any room has no nation and no operation on the wire (lobby has no field for it).
- Sectors are hard-coded to three (`ASSAULT_LINE_FRACTIONS`); waves revive the same first k.

## Design
1. **Team arrangement settings** (per mode, owner-facing, in the play menu mode card and the
   room settings): `enemyNation` (any | list from CAMPAIGN_ENEMY_NATIONS + every fleet nation),
   `waveSize` (horde: 4..12 start size), `enemyPool` (distinct enemy identities, 8..24),
   `allies` (0..6), and for Frontline `operationId` (campaign) or `nation` for a free sortie.
   Stored per mode (`cot.game.teams.v1`), threaded solo via `matchRulesetFor(mode, input)`
   (allies/enemies/nation) and on the wire as lobby fields → `buildPrivateMatchPlayers` →
   `createAuthoritativeMatch({ ruleset })` (parameter exists, unused today).
2. **Endless Horde**: a per-wave seeded draw from an enlarged, nation-filtered enemy pool
   (entities allocated at battle start, most deactivated); wave size = `waveSize` + escalation
   (+1 every wave, +1 extra every third wave), subset rotates each wave so no two consecutive
   waves share more than half their identities; after the pool is exhausted, identities recycle
   with the existing health/speed escalation; the HUD wave line shows "WAVE n · k HOSTILES ·
   next wave +m". Same-nation option = all bots from one nation (fallback to era peers only
   when the nation has fewer than `enemyPool` playable tanks).
3. **Frontline campaign**: every operation names its trench battlefield (`mapId`, variant
   `assault-trenches`, sector count 3..5, works density), its nation (already), waves per
   sector (2..3) of SAME-nation reinforcements that arrive from the enemy edge (placement
   `respawn` at the far pads, not revived in place), the operation's ally count and difficulty;
   more fortifications on the sectors (bunkers, wire, dragon's teeth, sandbag nests — extend
   `LINE_WORKS` / `placeTrenchWorks`); free Frontline sorties take the nation setting; rooms
   carry `operationId` so co-op plays the same operation.
4. Receipts to move: matchModes (wave census), matchRuleset (allies/enemies/lines),
   campaignOperations (fields), assaultLines (fractions per operation), matchPlacement,
   authoritativeMatch, net (lobby fields), privateMatchHandoff (bot fill), rosterPlanning
   (participant count), minimapObjectives, matchModeWorldPresentation, `.qa-dev/mode-loop.mjs`,
   GAME-MODES.md, i18n (both catalogs).
