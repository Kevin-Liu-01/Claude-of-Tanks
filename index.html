Kevin B. Liu

I designed and built Claude of Tanks as an experiment in how far one person can take an original browser game with persistent agent collaboration. Claude and Codex were development tools, not co-authors.

The vehicles, simulation, combat systems, interface, performance work, testing, documentation, and production pipeline were built end to end in a sustained workflow of many Claude and Codex agents. Every selectable tank is original procedural model work by Kevin B. Liu.
